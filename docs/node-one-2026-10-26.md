# 节点一：手机原首页自动同步（2026-10-26）

版本：`2026.10.26.1`。所有者已备份并明确授权手机更新后自动纳入现有待办和项目，不再逐项勾选或再次确认。本文取代首批记录中的预览纳入方案；其他分类仍为本机功能。本节点没有修改历史机制或做视觉优化。

## 实际行为和边界

- 原首页直接新增、编辑、完成/恢复和删除待办、项目；先提交本机 IndexedDB 事务，再由队列自动补传。页面打开、回前台、恢复联网及定时运行时拉取云端变化。关闭应用后的后台执行不保证。
- 只在正式站点 `https://ningle-42411164.github.io/personal-workbench/` 的手机浏览上下文自动首次纳入。使用移动系统、移动信号、触摸能力的组合，并排除桌面系统；不以小窗口等同手机。桌面和 localhost 隔离页不会自动上传其原有或新建的无绑定事项。
- 设备门控用于防误操作，不是身份认证，也不是唯一物理设备证明；用户使用其他已授权手机打开正式站点时同样满足条件。安全身份仍由所有者 OAuth、scope、PKCE 等校验负责。
- 复用保存的有效读写连接；恢复连接失败会再次调度，不阻塞本机编辑，也不自动循环跳转授权。原已知安装入口首次授权问题仍采用普通 Edge 授权后安装入口恢复连接的方式，没有声称改变浏览器 Cookie 行为。
- 首次纳入和绑定在同一事务内完成，保存设备标记与纳入 ID；既有绑定、版本、不可变 requestId 继续复用。重复执行、并发执行或刷新不会重新创建。用户明确暂停后，刷新不会自行重新开启。
- 相同 ID 已存在且内容一致时直接接纳服务端版本；内容不同或有删除标记时保留冲突，不静默覆盖。冲突副本另有本机保留标记，不被下一轮自动纳入。失败请求保留原 requestId 与内容；后续修改排下一次请求。
- 既有保存/草稿保护、v2 事项格式和原 LocalStorage 原文保留。旧窗口写旧存储、非法旧数据、超过 64 KiB 的单项请求会保留并提示阻塞，不通过删内容来兼容。无需日常上传按钮；连接和异常入口仍在页尾默认收起区域。
