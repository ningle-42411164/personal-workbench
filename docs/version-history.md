### 独立脱机版 1.0.0 · 2026-11-13

[对应提交 67cf1e4](https://github.com/ningle-42411164/personal-workbench/commit/67cf1e43eb13fe3e6903ab6272047b13a77f0010) · [正式 Release 与下载](https://github.com/ningle-42411164/personal-workbench/releases/tag/offline-v1.0.0)

- 从当前工作台建立独立脱机发行目标，保留事项、项目、标签、排序、置顶、收藏、历史、搜索、主题、日期提醒和本机备份，不以功能较少的历史版本代替。
- 本机保存使用独立 IndexedDB 事务；不启动云授权、自动同步、云冲突处理或远端 GPT／MCP 联动。
- 使用独立站点、数据库、偏好键、提醒冷却、通知通道与 PWA 缓存边界；两版不自动复制事项或授权，搬数据通过主动导出／导入备份完成。
- 提供默认构建脱机目标的专用源码包，以及已构建静态网页包。首次获取、缓存及更新仍需联网；网页包不是 Windows 安装包。
- 发布时两版构建及下载包检查已完成；断网重开、旧 PWA 共存交互与华为手机 Edge 脱机验收未验证，不能以构建通过代替。
